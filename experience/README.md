# Experience Stories Database

This directory contains your personal behavioral stories. 

## Git Safety
To protect your privacy, **all `.md` files in this folder are ignored by Git** (as configured in the root `.gitignore`), except for this `README.md`. You can safely write, edit, and keep your personal stories here without worrying about accidentally committing them to a public GitHub repository.

## How to Write a Story
1. Copy the structure from [story_template.md.example](file:///Users/georg/Antigravity%20apps/behavioral%20interview/experience/story_template.md.example).
2. Create a new Markdown file, e.g., `experience/story_10_new_story.md`.
3. Populate it with your details following the **STAR-L** format.
4. When you run `npm run dev` at the project root, the ingestion script will automatically compile your stories into the web app, making them searchable instantly.
